# 小程序 UI 与复杂流程精确还原

## 基准

原小程序 `miniprogram/pages/**/index.wxml`、同名 `index.wxss`、页面脚本和原始 PNG 素材是唯一基准。iOS 只采用安全区、系统键盘、日期选择器和返回手势等必要的原生适配，不改变信息架构、字段、状态和操作顺序。

## 本轮范围

1. 首页顶部恢复为全宽渐变矩形，保留小程序装饰圆点，并使用原始 `wave.png` 形成底部白色波浪，不再用圆角卡片替代。
2. 首页提醒、快捷入口和近期排课使用小程序的间距、色带标题、图标、进度和下一节课信息。
3. 新建班级恢复班级信息、课程模板、班型、计费方式、主题色、固定/自由排课、重复预设、多星期、多时段、具体日期、地点、开课日、单次课费、单次时长和预付课时。
4. 添加学生恢复姓名、年级、年龄、地址、基础课时、多班级选择、默认课时回填和备注；保存时一次完成学生建档与班级成员/课时档案建立。
5. 教师端所有“创建班级”和“添加学生”入口统一进入完整页面，移除仍在使用的简化表单。

## 验收

- 首页头部轮廓、比例、渐变和波浪与小程序源码一致。
- 新建班级和添加学生的字段、条件显示、验证与数据写入路径完整。
- 原 PNG 图标正常解码，页面无空白色块或临时占位图。
- 最终仅执行一次架构检查、Release IPA 构建和单元测试。
